# 语音稿整理 格式规范

各节用途：

| 节 | 用途 | 对应流程 |
|----|------|----------|
| 零 | 元数据块（YAML Frontmatter）与修订说明格式 | 前置准备 |
| 一 | 金句精选 + 关键洞察的格式与示例 | 第五步 |

| 三 | 课堂实录专属——分级保真标注 + 时间戳标注 | 课堂实录场景 |

## 零、前置准备：元数据块与修订说明

### 0.1 基础元数据块（YAML Frontmatter）

所有场景统一使用，字段对齐 Obsidian「讲座笔记模板」：

```yaml
---
title:           # 标题（同文件名主标题，如"第13课 东汉的兴衰"）
type: lecture_note  # 固定值
speaker:         # 发言者姓名全称（含单位头衔）
date:            # 日期（YYYY-MM-DD 格式）
event:           # 活动名称：讲座/会议/培训全称
event_type:      # 活动类型：培训 / 讲座 / 教研 / 课堂实录 / 说课 等
host:            # 主办方
level:           # 层级：国家级 / 省市级 / 校级 等
theme: []        # 主题关键词列表，如 [七年级, 教材答疑]
tags: []         # 标签列表，如 [培训, 国家级, 七年级, 教材答疑]
category:        # 分类归属，如 课标与教材 / 教育教学
related: []      # 相关笔记的 wikilink 列表
---
```

**字段映射对照**：

| 模板字段     | 对应原字段 | 填写说明                                                    |
| ------------ | ---------- | ----------------------------------------------------------- |
| `title`      | 文件主标题 | 同文件名主标题，不含后缀                                    |
| `type`       | —          | 固定 `lecture_note`                                         |
| `speaker`    | 发言者     | 姓名全称，可选加单位/头衔                                   |
| `date`       | 日期       | 发言/活动日期，ISO 格式 `YYYY-MM-DD`                        |
| `event`      | 场合/会议  | 讲座/培训/活动全称                                          |
| `event_type` | 场景       | `培训` / `讲座` / `教研` / `课堂实录` / `说课` / `研讨`  等 |
| `host`       | —          | 主办方                                                      |
| `level`      | —          | 活动层级                                                    |
| `theme`      | 主题       | 关键词列表                                                  |
| `tags`       | —          | 标签列表，较 `theme` 更细粒度                               |
| `category`   | —          | 分类归属，如 `课标与教材` / `教育教学`/ `名家通识讲座`等    |
| `related`    | —          | 相关笔记 wikilink，初始 `[]`，后续可在 Obsidian 补充        |

> 信息从文件名/文本提取，缺失留空/保持默认值；`theme`/`tags` 默认 `[]`，`related` 默认 `[]`。
> 课堂实录的**时长**信息不再纳入 frontmatter，如需记录可在正文首行以 `> 时长：约N分钟` 注明。

### 0.2 修订说明（可选）

仅当底本存在突出质量问题或有额外校对依据时填写，底本良好则省略。

**模板**：

```
> **整理说明**：本文原始底本为 ASR 语音转文字逐字稿，**底本质量判定**。专有名词、文献引文、核心内容等已据 **校对依据** 逐项核实修正；口语化表述和现场互动细节在保留现场感的前提下做了规范整理，不排除个别词句与原话存在细微出入。文中各环节的小标题为整理者根据内容结构所加，非原话。
```

**各要素填写指南**：

| 要素 | 说明 | 示例 |
|------|------|------|
| 底本质量判定 | 如实描述 ASR 残损程度 | "部分段落识别严重残损、存疑较多" / "少量专有名词误识" |
| 校对依据 | 明确标注核验参照物 | "本次公开课 PPT 原件（PDF）" / "同题正式出版论文" / "视频回放核对" / "公共知识" |
| 修正范围 | 区分已核实部分与推断部分 | 专有名词/文献引文/核心数据已核实 vs 口语化表述可能有出入 |
| 小标题声明 | 标注为整理者所加 | "文中各环节的小标题为整理者根据内容结构所加，非原话" |
| 不确定边界 | 底线声明 | "不排除个别词句与原话存在细微出入" |

**完整示例**：

> **整理说明**：本文原始底本为 ASR 语音转文字逐字稿，**部分段落识别严重残损、存疑较多**。专有名词、文献引文、核心内容等已据本次活动的材料原件（PDF）逐项核实修正；口语化表述和现场互动细节在保留现场感的前提下做了规范整理，不排除个别词句与原话存在细微出入。文中各环节的小标题为整理者根据内容结构所加，非原话。

**归档时的精简版**（去人物化、强调出处）：

> **整理说明**：本文原始底本为 ASR 语音转文字逐字稿，**部分段落识别严重残损**。专有名词、文献引文、核心内容等已据活动材料（见附件同名文件）逐项核实修正；口语化表述在保留现场感的前提下做了规范整理，不排除个别词句与原话存在细微出入。文中各环节小标题为整理者所加，非原话。

**历史课例库归档时的精简版**（历史学科专用，去人物化、指向课例库 PDF）：

> **整理说明**：本文原始底本为 ASR 语音转文字逐字稿，**部分段落识别严重残损**。专有名词、文献引文、核心史实等已据该课 PPT 原件（见课例库同名 PDF）逐项核实修正；口语化表述在保留现场感的前提下做了规范整理，不排除个别词句与原话存在细微出入。文中各教学环节小标题为整理者所加，非原话。

### 0.3 版权声明

课堂实录**必写**，讲座酌情添加。

**模板**：

```
**版权声明**：本实录著作权归 **发言者** 所有，整理版仅供专业研究与研修参考，请勿用于商业用途或公开传播。
```

**填写要点**：

- `**发言者**` 替换为实际姓名
- 若发言者为单位/机构名义发言，调整为"本实录著作权归 **单位名称** 所有"
- 讲座类若发言者未明确要求可不写，但课堂实录一律写入

## 一、第五步输出：金句精选与关键洞察

文末「整理者附章」统一用父章 `## 金句精选与关键洞察`，下设两个 `###` 子节。

### 1.1 金句精选（`### ✨ 金句精选`）

- 摘录最具代表性、传播力、记忆点的原话，**5-10 句**
- 格式：`- "原话引用" (洞察类型)`
- 金句须为发言者原话或高度凝练的转述，保留原味，不擅自改写观点
- 洞察类型标签（据句意选一）：
  - `(战略洞见)` 方向性 / 全局判断
  - `(认知洞察)` 概念澄清 / 认知升级
  - `(思考启发)` 方法论 / 思维启发
  - `(情绪共鸣)` 价值 / 情感共鸣句
  - `(行业判断)` 领域趋势判断
  - `(学术洞见)` 史料 / 史实层面的专业判断（历史学科可加）
  - `(教学启示)` 可直接转化为课堂操作的启示（历史学科可加）

示例（通用场景）：

```
## 金句精选与关键洞察
### ✨ 金句精选
- "任何改革的核心不是技术，而是人的认知转变。" (战略洞见)
- "学生不是在课堂上学会思考的，而是在被追问中被迫思考的。" (思考启发)
- "我们用了十年才真正理解什么叫素养——不是知识多了，而是知道怎么用了。" (认知洞察)
```

示例（历史学科）：

```
### ✨ 金句精选
- "教材是国家事权，任何个人都无权擅自改动。" (战略洞见)
- "大一统始终是历史发展的主流，也是中华文明最鲜明的底色。" (认知洞察)
- "让问题生长在情境之中，而不是从结论反推问题。" (思考启发)
- "这一处的措辞改动，背后是课标对'早期现代化'的学术定论更新。" (学术洞见)
```

### 1.2 关键洞察·通用场景（`### 💡 关键洞察`）

- 整理者基于全文的深层提炼，**3-5 条**
- 格式：`- **加粗洞察点**：解释`
- 写法：反转 / 深化 / 连接
  - **反转**：指出本讲如何颠覆常规认知（"主流通常认为……本讲提出……"）
  - **深化**：比原话再进一层（"比 X 讨论更深刻的是……"）
  - **连接**：关联实际运用（"对实践者的启示是……"）
- 须源自本稿独到内容，忌万能套话

示例（通用场景）：

```
### 💡 关键洞察
- **改革的底层逻辑**：主流常把改革视为"换工具"，本讲揭示其本质是思维方式的系统性校准——每处改动都对应理念或标准的更新，实践者须从"为什么改"而非"改成什么"入手理解。
- **核心概念的当代转化**：本讲把传统概念对接当代实践，提示教学不应停在知识叙述，而要落实到今天的运用和认同。
```

示例（历史学科）：

```
### 💡 关键洞察
- **教材修订的底层逻辑**：主流常把修订视为"换表述"，本讲揭示其本质是国家事权下的系统性校准——每处改动都对应课标或学术定论的更新，教师须从"为什么改"而非"改成什么"入手理解。
- **大一统的当代转化**：本讲把古代"大一统"对接"中华民族共同体意识"，提示教学不应停在疆域叙述，而要落点到今天的认同教育。
```

### 1.3 课堂实录·评课视角

对齐听课笔记的「亮点 / 商榷」体例（历史学科若使用 Obsidian 课例库，可参照《听课笔记》《课堂观察》维度）：

- **【亮点】**：可迁移的教学设计或策略（问题链、史料深挖/案例深挖、情境创设、学法指导、重难点突破）
- **【商榷】**：可探讨或可优化处（提法陈旧、节奏失衡、重点不够突出）
- **【启示】**：我课可以怎么讲——具体可操作，忌"加强互动"等空话
- 观察维度：课的结构、重难点突破、板书与媒体、课堂气氛、学生参与、教学细节、课后反思
- 格式同上 `- **加粗点**：解释`，亮点+商榷+启示均衡覆盖，3-5 条

示例（通用场景）：

```
### 💡 关键洞察
- **【亮点】问题链层层递进**：从"事实是什么"到"为什么会这样"再到"对我们意味着什么"三问串联，学生始终在思辨，可移植到同类课型。
- **【亮点】案例深挖**：一个典型案例延伸到深层逻辑，论证落得实。
- **【商榷】前段讲授偏多**：导入后连续讲授近 15 分钟，学生自主探究时间被压缩，建议将部分内容转为探究任务。
- **【启示】我课怎么改**：下轮同类课改用"同一现象不同视角"对比图导入，替代直接给结论。
```

示例（历史学科）：

```
### 💡 关键洞察
- **【亮点】问题链层层递进**：从"通商战争？侵略战争？"到"可能赢？必然输？"三问串联，学生始终在思辨，可移植到我的战争类新课。
- **【亮点】史料深挖**：一张图片延伸到工业革命运用与人的意识，史料实证落得实。
- **【商榷】前段讲授偏多**：导入后连续讲授近 15 分钟，学生自主探究时间被压缩，建议将部分内容转为探究任务。
- **【启示】我课怎么改**：下轮《鸦片战争》导入改用"同一事件不同视角"对比图，替代直接给结论。
```

## 二、第一步骨架：结构化样式

- 标题层级：**单元 / 大主题统一用 `##`**（不用 `#`，以免与文末 `##` 收尾章争层级），子主题 `###`，更深 `####`，层层递进
- 文末收尾章「金句精选与关键洞察」同为 `##`，与正文各章并列、独立成「附章」
- 并列 / 对比 / 分类 / 阶段信息用表格：
  - 并列型：`| 要点 | 说明 |`
  - 对比型：`| 维度 | 状态A | 状态B | 含义 |`
  - 分类型：`| 类别 | 内容 | 要点 |`
  - 阶段型：`| 时间 | 阶段 | 代表 | 特征 |`
- 整理者补充 / 编者按用 `> ` 引用块，与发言者原文区分

## 三、课堂实录专属格式

课堂实录特有的标注格式，与 SKILL.md「内容价值分级」（L0/L1/L2 定义）配合使用。

### 3.1 分级保真标注（L1 精简 + L2 剔除）

**L1 精简标注格式**：

```
【互动·已精简约N分钟：精简内容简述】
```

**L2 剔除标注格式**：

```
【已剔除：原因简述】
【已剔除：设备杂音约1分钟】
【已剔除：隐私内容·学生XXX】
```

**L1 精简示例**（先辨认知差异，再决定处理方式）：

```
## 一、核心主题（课堂实录 · L0+L1）

### 师：核心问题？
（核心讲解 L0 全保真，此处省略）

### 生答与互动（L1 精简）

#### 识记性问答（认知同质，已合并）
- 师连问，生齐答，多生附和。 【互动·已精简约1分钟：原为逐个追问】

#### 开放性问答（认知差异显著，分条保留）
- 师问"如何看待这一现象？"
  - 学生XXX："从正面看，这是进步的表现。"（正向视角）
  - 学生XXX："也有负面影响，不能忽视。"（反向视角）
  - 学生XXX："我觉得应该全面分析……"（辩证思维萌芽）
  【互动·已精简约3分钟：原为多轮鼓励补充与个别离题插话，认知差异部分保留】
- 师小结："这不仅是表象，更是深层逻辑的体现。"（L0 保真）
```

**红线**：L1 精简须遵循三原则——信息点不丢、辨认知差异保留典型样本、标注而非隐匿。学生回答中的认知差异（典型误区、不同理解层次、论证方式）是学情诊断的关键证据，不可因"同类多轮"而合并抹平。L2 内容整体移除、正文不保留，仅留一行 `【已剔除：…】`。

### 3.2 时间戳标注

> 标题层级说明：示例以「单元/大主题 `##` + 教学环节 `###`」演示；若全篇仅为单节课、无更高单元划分，则教学环节直接作为 `##`（如 `## 一、导入`）。

**完整示例**（约40分钟课堂）：

```
## 《课题名称》课堂实录
### 一、导入：复习旧知 + 情境创设 【00:00-03:15】
（正文 L0）

### 二、新课讲授：核心内容探究 【03:15-15:30】
#### 师讲解：关键概念解析
（正文 L0，此处省略）

【12:05】 师出示典型材料，生逐段解读
（关键节点·独立时间点标注）

### 三、小组合作探究：问题讨论 【15:30-28:00】
（正文 L0+L1）
【互动·已精简约4分钟 20:00-24:00】

### 四、课堂小结与作业布置 【28:00-35:00】
（正文 L0）

【已剔除：下课铃+收拾物品 35:00-37:00】
```

**简洁版**（无关键节点）：

```
## 《课题》课堂实录
### 一、导入：情境导入 + 问题驱动 【00:00-04:00】
### 二、新课讲授 【04:00-30:00】
  （各子目按内容分段，每段标注区间）
### 三、课堂小结 【30:00-35:00】
### 四、巩固练习 【35:00-40:00】
【互动·已精简约5分钟 08:00-09:00 / 15:00-16:30 / 22:00-24:30】
```

**无时间戳兜底**（原始文本无任何时间戳来源时）：

```
## 《课题》课堂实录
### 一、导入：情境导入 + 问题驱动
### 二、新课讲授
  （各子目按内容分段，仅用序号组织，不标注时间）
### 三、课堂小结
### 四、巩固练习
【互动·已精简约5分钟：原为多轮机械追问】
```

**标注规格**：

- 时间段 `【MM:SS-MM:SS】`：标注在教学环节标题末尾或段落开头
- 绝对时间点 `【MM:SS】`：标注在可独立回看的关键节点前（精彩问答、深度解读、案例演示等）
- L1 精简：在精简标注中追加时间段，如 `【互动·已精简约4分钟 20:00-24:00】`
- L2 剔除：在剔除标注中记录时间段，如 `【已剔除：设备调试 00:00-00:45】`
- 无时间戳来源 → 不标注时间，改用环节序号（不臆造时间）
