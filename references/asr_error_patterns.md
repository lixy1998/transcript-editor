# ASR 语音识别常见错误模式（讲座逐字稿通用排查指南）

处理语音转文字原始转录时，按类别系统排查。以下示例取自历史教学讲座，其他学科可类比套用。

---

## 一、专有名词误识（危害最大）

- 人名、地名、遗址名、书名、制度名最易被错识，须对照教材与权威资料**逐条核实**
- 规律：多字词、专业术语、古地名是重灾区
- 示例（历史领域）：叶小兵（非叶小平）、苏秉琦（非苏炳奇）、良渚（非两种）、陶寺（非陶瓷）、崇文抑武（非重文轻武）、一条鞭法（非一条编法）

## 二、同音/近音误识（高频）

- 常见词被替换为同音词：义务教育↔玉教、探源工程↔团圆工程
- 书名/篇名：《资治通鉴》（非子有）、《齐民要术》（非齐名要素）
- 排查法：通读时"怀疑一切"，对可疑词联想同音可能

## 三、学术概念 / 术语偏差

- 教材新修订术语须用新表述：早期现代化（非近代化）、尊崇儒术（非独尊儒术）、十二表法（非十二铜表法）
- 学科基石术语须准确：古国时代、聚落、考古学文化、五种社会形态等

## 四、数字与时间

- 统计数字最易错：样本量、条数、百分比、年份、月份
- 示例：900 多幅（非 900 多条）、1597 条（非 1600 多条）、12 月（非十二二）
- 凡数字须与上下文逻辑核对

## 五、断句错误

- 因无标点或误切分导致语义翻转
- 示例："反教材注重"=反映了教材注重；"学类官府"=学在官府
- 排查：凡句子读不通，先怀疑是不是断句错了

---

## 自查流程（每篇逐段）

1. 专有名词关 → 2. 学术概念关 → 3. 同音关 → 4. 断句关 → 5. 数字关

不确定内容 → 用 `【?】` 标记，不臆测。
