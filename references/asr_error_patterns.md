# ASR 语音识别常见错误模式（逐字稿通用排查指南）

处理语音转文字原始转录时，按类别系统排查。以下示例分「历史学科」与「通用领域」两节，其他学科/领域可类比套用排查思路。

---

## 一、专有名词误识（危害最大）

- 人名、地名、机构名、书名、术语最易被错识，须对照权威资料**逐条核实**
- 规律：多字词、专业术语、生僻名称是重灾区
- 排查思路：对听起来耳熟但不确切的词，先联想可能的正确术语再验证

### 历史学科示例

- 人名：叶小兵（非叶小平）、苏秉琦（非苏炳奇）
- 遗址/地名：良渚（非两种）、陶寺（非陶瓷）
- 制度/概念：一条鞭法（非一条编法）

### 通用领域示例

- 人名：C. P. Snow → C. P. Snowball、叶小兵 → 叶小平
- 地名/机构名：良渚 → 两种、敦煌 → 吨黄、UNESCO → 优尼斯科
- 专业术语：异化 → 一划、共轭 → 公鹅、元分析 → 原分析

## 二、同音/近音误识（高频）

- 常见词被替换为同音词：社交媒体 ↔ 设教媒体、基因测序 ↔ 基础程序、绩效管理 ↔ 几项惯例
- 书名/篇名/报告名：篇名中非常用词最易被误识
  - 历史学科：《资治通鉴》（非子有）、《齐民要术》（非齐名要素）
- 排查法：通读时"怀疑一切"，对可疑词联想同音可能

## 三、学术概念 / 术语偏差

- 领域新修订的术语须用新表述，注意区分新旧说法
  - 历史学科：早期现代化（非近代化）、尊崇儒术（非独尊儒术）、十二表法（非十二铜表法）
- 学科基石术语须准确：概念的内涵与外延不能因同音而替换
  - 历史学科：古国时代、聚落、考古学文化、五种社会形态等
- 排查思路：不确定的术语→暂停→查证领域权威来源确认正确表述

## 四、数字与时间

- 统计数字最易错：样本量、条数、百分比、年份、月份
- 示例：900 多份（非 900 多条）、1500 条（非 1500 多份）、12 月（非十二二）
- 凡数字须与上下文逻辑核对：数据口径是否合理、数量级是否异常

## 五、断句错误

- 因无标点或误切分导致语义翻转
- 示例："反教材注重" = 反映了教材注重；"学类官府" = 学在官府；"连算法" = 机器学习中的"联算法"
- 排查：凡句子读不通，先怀疑是不是断句错了

---

## 自查流程（每篇逐段）

1. 专有名词关 → 2. 学科术语关 → 3. 同音关 → 4. 断句关 → 5. 数字关

不确定内容 → 用 `【?】` 标记，不臆测。
