# 音视频文稿整理

把语音转文字（ASR）稿整理成规范、可读、可检索的结构化文本，并附「金句精选 + 关键洞察」。

适用于：通识讲座、教学培训、教材/标准修订培训、教研活动、说课评课、专题解读、答疑回应、课堂实录、试卷讲评，以及视频播客/深度访谈。

## 核心主张

1. **按内容价值分级保真**——核心讲解（L0）不删不改不压；外围互动（L1）可精简但必须留痕标注；技术噪音与无关内容（L2）整体剔除并标注。
2. **时间戳是结构的一部分，不是装饰**——不照抄 ASR 的停顿切分，而是按内容单元整合，锚点标在**标题层级末尾**（章／节），段落前不挂时间戳。
3. **访谈要标主体**——段首 `**说话人**：`，让问答切换一眼可见，也便于按人检索。
4. **任何推断都要可见**——不确定处标 `【?】`，末尾汇总成「存疑标记汇总」表交用户核对。

## 目录结构

```
音视频文稿整理/
├── SKILL.md                        # 主流程与规范（五步法、时间戳规范、自查清单）
├── README.md                       # 本文件
├── references/
│   ├── templates.md                # 元数据块、金句/洞察、结构化样式、时间戳规范示例
│   └── asr_error_patterns.md       # ASR 常见错误模式与排查清单
└── scripts/                        # 配套脚本（Python 3，仅用标准库）
    ├── seg_dump.py                 # 抽取带时间戳的段落骨架，供语义分组与说话人判定
    ├── reflow_ts.py                # 按映射表重建段落（合并区间 + 主体标注 + 节点）
    ├── reflow_levels.py            # 层级化重构：时间戳上移到章/节标题，段落只留说话人
    ├── strip_chapter_rules.py      # 去掉章节之间的分隔线
    ├── verify_reflow.py            # 核验段数/时间轴/主体分布/结构
    ├── verify2.py                  # 去标签后逐字比对，证明正文零丢失
    └── verify_levels.py            # 核验"层级锚点"体例
```

## 快速开始

1. 读 `SKILL.md`，确认场景（讲座/课堂实录/访谈）与保真档（L0/L1/L2）
2. 搭骨架：补标题层级、分段，并列/对比信息转表格
3. 修 ASR 错误（参照 `references/asr_error_patterns.md`）
4. 规范语气词 → 加粗核心观点 → 追加金句与洞察
5. 交付前过一遍「交付前自查清单」；涉及时间戳的用 `scripts/` 核验

脚本用法示例（均把结果写入文件，便于在无 stdout 回显的环境下使用）：

```bash
python scripts/seg_dump.py 原稿.md segs.txt 40     # 段落骨架
python scripts/reflow_levels.py 整理稿.md           # 时间戳层级化
python scripts/verify_levels.py 整理稿.md 旧稿.bak  # 核验（含正文零丢失证明）
```

## 时间戳规范（本技能的默认体例）

- 区间标在 `##`（章）／`###`（节）标题末尾：`## 二、…… 【02:32-14:47】`
- 区间取该层级所辖段落范围（起＝首段起点，终＝末段终点）
- **段落前不标时间戳**；访谈类段首只标 `**说话人**：`
- 关键节点（可选）用 `【MM:SS】` 标在**段内**，标在段首即与标题区间重复
- 无时间戳来源的纯文本：不标，改用环节序号组织
